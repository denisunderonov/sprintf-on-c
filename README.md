# s21_string+

Учебный проект на **C** в рамках School 21 — собственная реализация части стандартной библиотеки `string.h` с дополнительной реализацией `sprintf` и `sscanf`.

## Что было сделано

* реализованы основные функции `string.h`;
* написана собственная версия `sprintf`;
* добавлена поддержка форматирования: `%c`, `%d`, `%f`, `%s`, `%u` и других спецификаторов;
* реализованы флаги, ширина, точность и модификаторы типов;
* реализована `sscanf`;
* добавлены дополнительные функции обработки строк;
* написаны unit-тесты;
* настроена проверка покрытия кода;
* библиотека собирается как статическая `s21_string.a`.

## Стек

* C11
* GCC
* Makefile
* Check
* gcov
* Static Library

## Что изучено

Проект помог закрепить работу со строками и массивами символов в C, указателями, динамической памятью, variadic functions (`va_list`), форматированием данных, тестированием и структурой статических библиотек.

## Цель

Получить практический опыт разработки низкоуровневых функций на C и лучше понять, как работают стандартные функции обработки строк и форматированного вывода.
